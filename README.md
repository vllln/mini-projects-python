# 🚀 Моя коллекция мини-проектов на Python

Добро пожаловать! В этом репозитории я собираю свои небольшие проекты, консольные игры и полезные утилиты на Python, которые создаю в процессе обучения.

## 📂 Структура репозитория

Каждая папка — это самостоятельный проект со своей логикой и кодом. Вы можете кликнуть по названию любого проекта, чтобы перейти в его папку:

- 🎮 [guess_game_python](guess_game_python) — классическая консольная игра «Угадай число» (Stepik).
- ✊ [rock_paper_scissors_python](rock_paper_scissors_python) — интерактивная игра «Камень, ножницы, бумага».
- 💼 [smart_wallet_python](smart_wallet_python) — умный кошелёк для контроля расходов, хранения истории покупок в словарях и вывода отчётов.
- 📊 [split_it_python](split_it_python) — удобная утилита для быстрого и честного разделения счёта.
- 🪙 [kopeyka_python](kopeyka_python) — учебный мини-проект «Копейка».

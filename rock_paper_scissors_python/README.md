# Консольная игра «Камень, ножницы, бумага» 🪨✂️📄

Моя собственная реализация классической игры на Python. 

## 🕹️ Как устроена игра
* Компьютер случайным образом выбирает своё оружие (камень, ножницы или бумага).
* Игрок вводит свой вариант ответа в консоль.
* Программа сравнивает комбинации через условия и определяет, кто победил в раунде.
* Игра длится 2 раунда.

## 🚀 Запуск
```bash
python main.py
```

# Консольная игра «Угадай-ка» 🐍

Простая текстовая игра на Python, написанная в рамках обучения. Компьютер загадывает число, а игрок пытается его угадать.

## 🕹️ Суть игры
1. В самом начале программа выводит правила.
2. Компьютер один раз загадывает случайное число от 1 до 3 включительно.
3. Игра состоит из **3 раундов**, в каждом из которых игрок вводит свой вариант.
4. Программа проверяет ввод и сразу отвечает, угадал игрок или нет.
5. В конце выводится общее количество успешных попыток и финальный вердикт в зависимости от результата.

## 🚀 Как запустить игру у себя
Для запуска вам понадобится установленный Python версии 3.x.

1. Скачайте файл `main.py` из этого репозитория.
2. Откройте терминал или командную строку в папке с файлом.
3. Запустите игру командой:
   ```bash
   python main.py
   ```
